# 拾い帳(iPhone・PC 共通のアプリ)

図面(PDF・画像)の上で鉄骨を拾い、台帳・集計を作り、Excel に書き出すアプリです。
ブラウザで動くアプリなので、App Store を通さずに iPhone のホーム画面に置いて使えます。電波がなくても動きます。

## GitHub に置く(最初の1回)

1. GitHub で新しいリポジトリを作る(例: `hiroicho`)。
   - 無料プランで GitHub Pages を使うには、リポジトリを **Public** にする必要があります。
   - Public でも、置かれるのはアプリの仕組みだけです。図面や拾ったデータは、それぞれの端末の中にしか保存されません。
   - Private のリポジトリから Pages を出すには有料プラン(GitHub Pro など)が必要です。その場合も、公開されたページ自体は URL を知っていれば誰でも開けます。
2. ファイルを全部アップロードする(全部で 24 個。フォルダはありません)。
   - PC: リポジトリの画面の「Add file」→「Upload files」を開き、このフォルダの中のファイルを全部選んで(Ctrl+A)、まとめてドラッグ →「Commit changes」。
   - iPhone: Safari で github.com を開き、「ぁあ」→「デスクトップ用Webサイトを表示」にしてから「Add file」→「Upload files」→「choose your files」で、ファイルアプリの中の 24 個を全部選ぶ →「Commit changes」。
3. 「Settings」→「Pages」→「Branch」を `main`、フォルダを `/ (root)` にして「Save」。
4. 1〜2分待つと、`https://(ユーザー名).github.io/hiroicho/` で開けるようになります。

## iPhone に入れる

1. Safari で上の URL を開く。
2. 下の共有ボタン(□に↑)→「ホーム画面に追加」。
3. ホーム画面の「拾い帳」から開く(以後は電波がなくても使えます)。

※ ホーム画面から開いたときのデータと、Safari で開いたときのデータは別々に保存されます。いつもホーム画面から開いてください。

## PC で使う

Chrome または Edge で同じ URL を開きます(アドレスバー右の「インストール」でアプリのようにも使えます)。
マウスでは、クリック=タップ、ホイール=拡大・縮小、ドラッグ=移動です。

## iPhone と PC の受け渡し・控え

データは端末の中だけにあります。端末どうしで自動ではそろいません。

- 書き出す: 台帳 →「書き出し」→「PC に保存」か「iPhone で保存」の「案件ファイル」(`.hiroicho`)。
- 読み込む: 最初の画面 →「案件ファイルを読み込む」。いつも案件として足します(同じ案件があるときは、別の案件として入ります)。
- 置き換える: 最初の画面で、置き換えたい案件の「⋯」→「案件ファイルで置き換える」。その案件の案件ファイルだけ受け付けます。この端末のほうが新しいときは、確かめてから置き換えます。
- iPhone を使わない日が続くと、保存したデータが消されることがあります(iPhone の決まり)。ホーム画面から開くこと、区切りごとに案件ファイルを書き出して控えを取ることをおすすめします。

## 使い方(短く)

- 部材が多いとき: 台帳の「部材」や「部材を選ぶ」で「拾った部材だけ」にすると、数量のある部材だけが出ます。名前で探すときは全部の部材から探せます。Excel に入れる部材は、これとは別に、台帳 →「書き出し」の「Excel に入れる部材」で選びます。
- 部材: 下の「部材」→「一覧・貼り付け」。右上の「標準の部材」で、いつもの部材(ボルト数つき)をまとめて入れられます。Excel の「部材名・種類・単重・ボルト・柱/G/B/他」の列をコピーして貼り付けると、まとめて入ります。
  - 柱/G/B/他 を選ばなかった部材は、名前で決まります(「柱」を含む→柱、G を含む→G、B を含む→B、それ以外→他)。
- 拾い: 個はタップ1回、m・部材は始点と終点をタップ。図面の線や線の端に吸い付きます。
  - 細かく合わせたいときは長押し → 指の下が拡大されるので、合わせて指を離した所に置きます。
  - 印をタップすると「消す」「この部材を選ぶ」が出ます。
- 「強調」(下の部材の欄の右): 全部の部材を濃く表示し、線の横に部材名と吊・手付を出します。
- 図面を消す: 図面名 →「図面を消す(選んで)」でチェックした図面を消します。「消した図面を戻す」で拾った印ごと戻せます。二度と戻せないように消すときは、別のボタン「消した図面を完全に消す」を使います。
- 拡大・縮小は指2本、移動は指1本でなぞる。拡大すると、見えている所が細かく描き直されます。
- 書き出す図面: 台帳 →「書き出し」(または「集計」)→「図面を選ぶ」で、書き出す図面にチェック。Excel・PDF・工区毎P算出は選んだ図面だけになり、図面1枚で1列(数量1・数量2…)になります。
- 伏図: 1枚の図面に 2F・3F… と並んでいるときは、「伏図」で範囲の対角の2点をタップして名前を付けます。その図面は範囲ごとの列になります(範囲の外は入りません)。
- 工区: 角を順にタップ → 最初の点をタップで閉じる → 名前。同じ名前の工区は、別の伏図・別の図面でも同じ工区として数えます。
  - 工区を写す(1枚の図面に 2F・3F… が並んでいるとき): ①「伏図」で各階の範囲を囲む → ②「工区」で写す元の階に工区を描く → ③「伏図」で写す元の範囲をタップ →「この工区をほかの伏図に写す」→ ④ 写す先を選ぶ → ⑤ 写す元で通り芯の交点などをタップ → ⑥ 写す先で同じ交点をタップ。別の図面(別のページ)には写せません。
  - 写すときは、伏図のメニューで「写す先に足す」か「写す先の工区と入れ替える」を選んでから始めます。
  - 工区をタップ →「角を動かす」で形を直せます。
  - 名前を変える: 工区をタップ →「この範囲の名前を変える」(ほかはそのまま)か、「〇〇をまとめて名前を変える」(同じ名前の工区が全部変わる)。
- 仕口ちがい: 部材の編集で部材をタップ →「分割(仕口)」で G24rr・G24rp などを作れます(ボルトだけ変えられます)。拾った印をタップ →「部材を変える」で付け替えられます。
- 縮尺(この図面だけ): 上の「1/100」をタップして数字を入れるか、「2点で合わせる」。ほかの図面は変わりません。
- 縮尺(全部の図面): 上の図面の名前 →「全部の図面の縮尺を変える」。
- 図面を追加すると、そのとき開いていた図面の縮尺が入ります(帯で知らせます)。
- 部材を選ぶ: 上の欄で探して見つからなければ、「＋ 部材を追加」でその名前のまま追加できます。各部材の重さ・ボルト・柱/G/B/他も一覧に出ます(未設定は赤字)。
- 部材の並べ替え・絞り込み: 部材を選ぶ・部材の編集・台帳の集計の「並べ替え・絞り込み」。並べ替え(入れた順・名前・重さ・ボルト。もう一度押すと逆順)は部材の順番そのものを変え、Excel の順番も変わります。絞り込み(重さ・ボルトの入っている/未設定、柱/G/B/他、種類)は見た目だけです。
- 図面を消す: 上の図面の名前 → 一覧で消したい図面の左にチェック →「消す」。
- 図面の並べ替え: 上の図面の名前 → 一覧の ↑ ↓。Excel・PDF・工区毎P算出の「数量1・数量2…」もこの順番になります。
- 図面のコピー: 上の図面の名前 →「この図面をコピー(図面だけ)」。拾った印・工区・伏図・作業半径は入りません。
- 作業半径(ラフタ): 下の「半径」→ ラフタの中心をタップ →「半径を数字で入れる」か「届かせたい所をタップ」。中心をタップすると円を何重にも足せます。円をタップ →「扇にする」→ 残す範囲の両端をタップ(1点目から時計回りの範囲が残ります)。図面と印刷用 PDF に描くだけで、数量には入りません。縮尺を入れた図面で使えます。
- PC のキー: ← → で前後の図面に移動(見直しの間は効きません)。Ctrl+Z で元に戻す。Esc で入力途中の取り消し。
- 何かが変わったときは、画面の下に帯で知らせます。OK を押すまで残りますが、出たままでも作業は続けられます。
- 見直し: 印を1つずつ順に表示します。合っていれば「OK → 次」、違えば「消す」。全部 OK になれば見落としなし。台帳の「確認」に、見直しの進み具合と気になる点(二重に拾っていそうな所なども)が出ます。
- 書き出し: 台帳 →「書き出し」。PC では「PC に保存」(そのままダウンロード)、iPhone では「iPhone で保存」(共有の画面 →「"ファイル"に保存」)のボタンを押します。
- Excel:部材 / 集計 / 吊材積算・手付積算 / 工区毎P算出 の表になります。
- 印刷用の PDF:拾った印を描いた図面(線の長さ・部材名・重さ・工区つき)と、その次のページにその図面の部材の表が入ります。

## 更新するとき

ファイルを入れ替えてアップロードしたら、`sw.js` の上のほうの `VER = 'hiroicho-v28'` の数字を1つ上げてください(`v29` など)。`app.js` の `APP_VER = 'v28'` も同じ番号にします(最初の画面の「拾い帳」の横、図面の画面の縮尺の右、台帳の「書き出し」の下に出る版の番号です)。端末の中の古い部品が新しいものに入れ替わります。アプリを2回開き直すと新しい版になります。
